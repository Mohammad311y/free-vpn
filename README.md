# FreeVPN

کلاینت VPN اندروید با هسته **Xray** (پشتیبانی از VLESS / VMess / Trojan / Shadowsocks).
سرورها به‌صورت خودکار از لیست‌های عمومی جمع‌آوری می‌شن (چندتاش مستقیم از کانال‌های تلگرام کالکت می‌کنن).

## امکانات
- دریافت خودکار سرورهای رایگان از چند منبع + حذف تکراری‌ها
- افزودن کانفیگ از کلیپ‌بورد (کانفیگ‌هایی که توی تلگرام می‌بینی رو کپی کن و دکمه paste رو بزن)
- تست پینگ TCP برای همه + تست **Real Delay** از داخل هسته برای ۲۰ سرور سریع‌تر
- مرتب‌سازی بر اساس پینگ / نام / پروتکل و فیلتر پروتکل
- اتصال هوشمند: اگه سروری انتخاب نکنی، به سریع‌ترین وصل میشه
- رابط کاربری ویجتی Material You (رنگ‌ها از والپیپر گوشی)، پس‌زمینه متحرک، دکمه پالس‌دار، انیمیشن لیست
- لمس طولانی روی سرور = کپی کانفیگ

## ساخت فایل نصبی (APK) بدون نصب هیچ چیزی
1. یه ریپوی جدید توی GitHub بساز.
2. همه فایل‌های این پوشه رو آپلود کن (پوشه `.github` هم حتما باشه).
3. برو تب **Actions**، بیلد خودکار شروع میشه (حدود ۱۰ دقیقه).
4. فایل APK توی بخش **Releases** ریپو (یا Artifacts همون بیلد) آماده‌ست.
5. برای اکثر گوشی‌ها فایل `app-arm64-v8a-release.apk` رو نصب کن.

## ساخت روی کامپیوتر خودت
```bash
flutter create --org com.freevpn --project-name freevpn --platforms=android .
python3 tool/patch_android.py
flutter pub get
flutter build apk --release --split-per-abi
```

## منابع سرور
از آیکون تنظیمات داخل اپ قابل ویرایشه. این ریپوهای عمومی گاهی آدرس عوض می‌کنن؛ اگه یکی کار نکرد، لینک subscription جدید جایگزین کن.

> سرورهای رایگان عمومی ناشناس‌اند: برای کارهای حساس (بانک، رمز) بهشون اعتماد نکن.
